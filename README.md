# Marci Metzger Homes — Junior Website Builder Assignment

A redesigned home page for [marcimetzger.com](https://marcimetzger.com), a Pahrump,
Nevada realtor. Built as a single responsive page using the site's own content and
photos, with a darker, editorial layout, large serif type, and scroll-triggered motion.

Live site: published via GitHub Pages.

## Stack

Plain HTML, CSS and JavaScript — no framework or build step.

## Structure

```
index.html       Page markup
css/style.css     All styling
js/main.js        Mobile nav, scroll-triggered animation, header backdrop, contact form
images/           Photos and badges downloaded from the reference site
```
